# MAISON fragrance storefront

Live site: https://toubaslam.github.io/Test1/

Edit index.html, style.css, and app.js to customize this static store. Open index.html locally or use any static web server.

Includes search, category filters, product details, scent finder, and a cart saved in the browser.

Products and prices are illustrative. Checkout and email signup are demos; no payments are collected or orders fulfilled.
