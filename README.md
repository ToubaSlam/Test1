# MAISON fragrance storefront

Static fragrance concept storefront with search, category filters, product details, scent finder, and a browser-local cart.

Live site: https://toubaslam.github.io/Test1/

Open `index.html` locally or serve this folder with a static web server. Edit `index.html`, `style.css`, and `app.js` to customize the store.

Checkout and email signup are demonstrations. No payments are collected or orders fulfilled.
