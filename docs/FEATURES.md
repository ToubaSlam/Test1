# Actual-perfume storefront

The main shop now uses the actual ALT and Scentora perfume catalogs rather than a proposed Eden Musk collection. The current snapshot includes 225 perfume listings: 178 ALT and 47 Scentora. A separate source-data browser retains all 288 public listings, including non-perfume bundles, gifts, and store services.

## Product fidelity

| Detail | Behavior |
| --- | --- |
| Names and brands | Original product names and clearly visible ALT/Scentora branding |
| Product imagery | Actual retailer photos and galleries; no relabeled Eden Musk bottle art |
| Descriptions | Original wording based on published fragrance facts and references |
| Inspiration | Named retailer reference where reliably provided; featured ALT references checked against public product/home pages |
| Notes | Names mentioned in source text plus original retailer note diagrams; no invented top/heart/base assignments |
| Bottle options | Exact listed variant titles, including ALT 30/60/100 ml and Scentora 50 ml where supplied |
| SKU and prices | Exact source SKU and integer-cent prices; source compare-at values distinguished from designer retail price |
| Variant photo | Matching source variant image selected where supplied |
| Ingredients | Published ingredient disclosure; otherwise the missing source field is identified |
| Concentration and origin | Product-level source fields, with Scentora brand-level claims explicitly identified where applicable |
| Availability | Dated source availability; unavailable options cannot be added to the planning bag |
| Source | Original retailer URL and snapshot date on each product page |

## Functional shopping features

- Main catalog: brand/category filters, keyword and inspiration search, note-family browsing groups, price limit, sorting, and 24-item pagination.
- Product pages: galleries, exact option selection, matching image, price, SKU, source stock, ingredients, note diagrams, per-10-ml pricing where volume is stated, specifications, FAQ, and sticky bag controls.
- Search, saved favorites, recently viewed items, and comparisons all use the actual products.
- Quiz recommendations draw from the actual catalog; note-family and mood matching are browsing guidance, not measured formulation claims.
- Three/five-product set builder supports real listed sizes. Choosing 50 ml excludes perfumes without that option rather than inventing a 50 ml variant. Default-option sets may contain different actual volumes.
- Bag rows preserve brand, SKU, exact option, quantity, and source price. Totals use variant prices with no invented promotions. Optional notes are stored as escaped text.
- Phone and desktop menus, original journal content, educational guide, FAQs, and source-data browser remain available.

## Not connected

Eden Musk stock, secure payment, real accounts, fulfillment/tracking, subscriber collection, verified review feeds, loyalty/referrals, gifts, and commercial policies still need the owner's data and services. The active bag is a planning tool, not an order. Source retailer offers and guarantees are not Eden Musk offers.

## Validation

Twelve unit/data tests cover source identity and exact variants/prices/SKU, full rendering of all 225 actual perfume pages, actual-size totals, filtering, recommendations, escaping, and the complete reference snapshot. Browser suites cover real photos/names, exact product options, size-dependent prices and SKU, bag persistence, notes, favorites, comparisons, size-aware sets, quiz results, pagination, source browsing, and 19 main routes at 1440, 390, and 320 pixels.
